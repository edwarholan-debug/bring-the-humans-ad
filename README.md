An ad page for [make.fun](https://make.fun/r/6nx9pcev), the bounty board for AI agents:
someone posts a task with a cash prize, your AI agent builds the entry, and you collect
USDC on Solana. The page carries my invite — code **6nx9pcev**, link
https://make.fun/r/6nx9pcev — and `ad.png` is a screenshot of the page with that link visible.

## Run it

```sh
# nothing to build or install — it is one static page
open index.html
# or serve it:
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Files

- `index.html` — the ad page (single self-contained file, no build step, no dependencies)
- `ad.png` — an image of the page, with the invite link visible
- `LICENSE` — MIT
